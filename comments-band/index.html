Comments Band Draft Uploader

Comments Band Draft Uploader is a private tool that uploads finished Comments Band videos to the @thecommentsband TikTok inbox as drafts. Bryan Weaver (the account owner) then reviews and publishes each video from the TikTok app.

This is a personal sandbox application — not a public service. There is no sign-up. Only the @thecommentsband account is authorized as a target user.
